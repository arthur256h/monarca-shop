# 🛒 MonarcaShop

E-commerce moderno desenvolvido com Next.js.

## 🚀 Tecnologias

- Next.js
- React
- TailwindCSS
- TypeScript

## ✨ Funcionalidades

- Listagem de produtos
- Página de produto
- Carrinho de compras
- Checkout funcional
- Interface responsiva

## 🌐 Deploy

https://monarca-shop.vercel.app/

## 📦 Como rodar o projeto

```bash
npm install
npm run dev
```
